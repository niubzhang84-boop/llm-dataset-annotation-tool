# 远元生物科技 - 私有AI知识库系统 v5.9 (Enterprise Private RAG System)

## 📌 项目简介
本项目是一款专为企业内网严苛安全审计环境设计的**私有化知识库检索增强（RAG）问答系统**。针对内网环境中防火墙拦截、禁用大模型 Embedding 向量接口、专用向量模型无法下载等极端硬件与网络约束，项目抛弃了传统的第三方向量数据库依赖，**纯手工实现了高维空间向量矩阵模型（VSM）**。

系统基于 **PyQt5** 构建现代化双栏交互前端，后端无缝对接本地离线部署的 **Ollama (Qwen2.5)** 大模型，实现了 0 外部依赖、高精准度、完全不出网的企业级私有规章语义检索与智能化问答。

---

## ✨ 核心技术亮点

### 1. 🧮 纯 Python 离线空间向量矩阵引擎 (VSM)
* **极端环境降级自愈**：在 Ollama 向量接口返回 `501 Not Supported` 或内网安全软件拦截专用向量模型下载的约束下，系统自动降级为纯数学矩阵运算模式。
* **手写 TF-IDF 与余弦相似度（Cosine Similarity）**：完全基于 Python 原生标准库与数学公式构建文本特征向量空间，毫秒级完成海量规章切片的夹角余弦值计算，彻底告别网络超时（Read timed out）。

### 2. ⚡ PyQt5 异步多线程架构 (QThread)
* **UI 渲染与计算分离**：将高密度的本地矩阵相似度计算、大模型 API 阻塞请求全面移至后台 `QThread` 线程。
* **信号驱动通信（pyqtSignal）**：通过自定义信号实现跨线程全安全通信，完美解决大语言模型长文本流式/全量响应时，前端软件界面“未响应”或假死的工业级痛点。

### 3. 🧩 智能滑窗文本分块与多格式解析
* **多源支持**：内置原生 `pypdf` 与文本清洗组件，支持企业 PDF/TXT 规章制度的自动化流式读取与标准化清洗。
* **语义连贯性保护**：采用 250 字符窗口大小、50 字符重叠度的滑动窗口算法进行文本切块，有效防止切片时截断上下文核心语义。

---

## 🛠️ 技术栈
* **前端界面**：PyQt5 (Python GUI)
* **核心算法**：手写向量空间模型 (TF-IDF, Cosine Similarity, 矩阵运算)
* **本地大模型**：Ollama (Qwen2.5:1.5b / Qwen2.5:7b)
* **文本解析**：pypdf

## 🚀 快速开始

### 1. 环境准备
确保本地已安装 Python 3.8+ 及本地大模型引擎 Ollama。
```bash
pip install PyQt5 requests pypdf
2. 启动本地大模型
确保你本地的 Ollama 服务已启动，并拉取了 Qwen 模型：
Bash
ollama run qwen2.5:1.5b
3. 运行主程序
将规章物理文件放入 documents 文件夹（或在界面中直接点击导入），然后运行：
Bash
python local_rag_client.py
