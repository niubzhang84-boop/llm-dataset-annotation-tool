# LLM 数据集注释工具 (LLM-Dataset-Annotation-Tool)

## 📌 项目简介
本项目是一款专为大语言模型（LLM）微调（Fine-tuning）设计的**离线语料自动化清洗与高可视化标注系统**。系统旨在解决大模型数据工程中，原始语料噪声多、质量低、手动标注效率底下的痛点，提供一站式的数据预处理与交互式标注方案。

---

## ✨ 核心功能
* **高效语料清洗**：内置流式文本清洗组件，自动化去除无效字符、重复数据与格式噪声。
* **现代化 PyQt5 标注界面**：支持一键加载、流式轮转、高亮显示，大幅提升微调数据的标注效率。
* **标准格式输出**：标注结果一键导出为标准的 JSONL 格式，无缝对接 LLaMA、Qwen 等主流大模型的微调数据集要求。
